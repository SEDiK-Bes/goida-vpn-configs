──────────────────────────────────────────────────────────────────────────────
1. Что уже настроено
──────────────────────────────────────────────────────────────────────────────

В папке .github/workflows уже есть рабочие GitHub Actions:

- frequent_update.yml
- goida.yml
- update-configs.yml

Они отвечают за автоматическое обновление конфигов в каталоге githubmirror
и другие служебные задачи.

То есть репозиторий уже умеет САМ:
- периодически запускать скрипты
- обновлять VPN-конфиги
- коммитить изменения в репозиторий

Никакой отдельный токен в открытом виде в коде НЕ используется — всё делается
через встроенные GitHub-токены и Secrets.

──────────────────────────────────────────────────────────────────────────────
2. Как убедиться, что автообновление работает
──────────────────────────────────────────────────────────────────────────────

1) Открой вкладку Actions в репозитории:
   - https://github.com/SEDiK-Bes/goida-vpn-configs/actions

2) В списке должны быть workflows:
   - frequent_update
   - goida
   - update-configs

3) Убедись, что у них есть последние успешные запуски (зелёные галочки).

Если запусков нет:
- зайди в любой workflow
- нажми кнопку "Run workflow" (Запустить workflow вручную)
- подожди завершения и посмотри логи

──────────────────────────────────────────────────────────────────────────────
3. Где лежит основной скрипт
──────────────────────────────────────────────────────────────────────────────

Основной Python-скрипт для обработки конфигов:

- main.py (в корне репозитория)

Он использует зависимости из файла:

- requirements.txt

GitHub Actions устанавливают зависимости и запускают нужные команды, описанные
в их .yml-файлах.

──────────────────────────────────────────────────────────────────────────────
5. Безопасность
──────────────────────────────────────────────────────────────────────────────

- НИГДЕ в репозитории не должны попадать личные GitHub-токены в открытом виде.
- Все чувствительные данные добавляются только в Settings → Secrets → Actions.
- Настройки workflow используют безопасные механизмы GitHub для доступа к
  репозиторию.

Если нужно добавить новый Secret:
1) Открой Settings → Secrets and variables → Actions → New repository secret
2) Введи имя (например, MY_TOKEN) и значение
3) Используй этот секрет в workflow через синтаксис: ${{ secrets.MY_TOKEN }}
