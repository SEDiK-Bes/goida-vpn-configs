## ⏰ КАК ЧАСТО ЗАПУСКАЕТСЯ?

Workflow запускаются **по расписанию** (cron-задачи в .yml файлах):

- **frequent_update.yml** — Частые обновления
- **update-configs.yml** — Обновление конфигов
- **goida.yml** — Основной workflow

**Точное расписание** определено в каждом `.yml` файле в строке `schedule:`

Пример:
```yaml
schedule:
  - cron: '0 */6 * * *'  # Каждые 6 часов
```

## ✅ КАК ПРОВЕРИТЬ, ЧТО РАБОТАЕТ?

### Способ 1: GitHub Actions (рекомендуется)

1. Открой: **GitHub → Actions**
2. Посмотри список workflows (frequent_update, goida, update-configs)
3. Нажми на workflow
4. Посмотри **последние запуски** (должны быть зелёные ✅ галочки)

### Способ 2: Проверить файл конфигов

1. Открой файл
```
https://github.com/SEDiK-Bes/goida-vpn-configs/blob/main/githubmirror/all.txt
```
2. Посмотри дату обновления (должна быть свежая)
3. Проверь наличие конфигов (файл не должен быть пустым)

### Способ 3: Запустить workflow вручную

1. GitHub → Actions
2. Выбери workflow
3. Нажми "Run workflow" (если кнопка есть)
4. Выбери "main" в качестве ветки
5. Нажми "Run workflow"
6. Подожди 1-2 минуты
7. Проверь результат (должна быть зелёная ✅)

## 🐛 ЧТО-ТО НЕ РАБОТАЕТ?

### Ошибка 1: Нет зелёных галочек в Actions

**Проверь:**
- Есть ли в `.github/workflows/` нужные `.yml` файлы?
- Нет ли синтаксических ошибок в yaml?

**Посмотри логи:**
- GitHub → Actions → [Workflow] → [run] → Логи

### Ошибка 2: Файл конфигов не обновляется

**Проверь:**
- Когда был последний запуск workflow?
- Может быть, расписание очень редкое?

**Решение:**
- Отредактируй cron в workflow файле
- Или запусти workflow вручную (кнопка "Run workflow")

### Ошибка 3: Скрипт падает с ошибкой

**Посмотри логи:**
- GitHub → Actions → [Workflow] → [run] → Логи

Там написано чего именно не сработало.
